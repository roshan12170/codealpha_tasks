# Iris Flower Prediction 🌸

This project uses Machine Learning to predict the species of an Iris flower based on:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Project Workflow

1. Load the Iris dataset
2. Perform data preprocessing
3. Split the data into training and testing sets
4. Train the Machine Learning model
5. Evaluate the model
6. Build a Streamlit web application
7. Predict the Iris flower species

## Output

The application predicts one of the following Iris species:

- Setosa
- Versicolor
- Virginica
